# ChatGPT API Integration

This project is a React app that integrates with a backend to generate SQL queries using OpenAI's ChatGPT model. The app provides an interface where users can describe a SQL query, and the app will generate the SQL code based on that description.

## Features

- User can describe a SQL query in plain text.
- The app sends the description to a backend server, which uses OpenAI's model to generate the corresponding SQL query.
- The generated SQL query is displayed to the user.
- The app is built using React and Bootstrap for responsive design.

## Technologies Used

- React.js
- Bootstrap
- OpenAI API (for generating SQL queries)
- Node.js & Express.js (for backend server)
